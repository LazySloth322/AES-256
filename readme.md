# AES-256

AES-256 algorithm written on java.

> [!NOTE]
> This code was written for educational purposes. It is highly unrecommended to use this code for real crypto systems

## Compilation
SDK: Oracle OpenJDK 24.0.1

```
> git clone https://github.com/LazySloth322/AES-256.git
> cd ./AES-256/
> javac Main.java
> java Main
```
